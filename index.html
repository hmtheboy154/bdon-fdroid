How this works

The publisher does not offer an API for its downloads, so the link to the Android package is hard-coded inside a hashed JavaScript bundle on the official website. A scheduled job reads the page, follows the bundles, extracts the download URL, and compares it with the version already published. Only when something has changed is the APK fetched — once, to compute its SHA-256 and read its manifest — and then discarded.

The APK itself is not stored here. The index points at the publisher’s own CDN, which is registered with F-Droid as a mirror, so installs and updates come from bilibili directly. This site only ever holds the index files and a few small images.
